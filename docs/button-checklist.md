# 按钮点击 checklist（逐条对照）

> 用户要求：「模拟从各个按钮点击，要做好测试的 checklist 逐条对比，
> 逐条进行对比，有错误就修改，不要出现这种很低级的错误。」
>
> 这个文件是**人可读的对照表**，机器断言在 `tools/test_buttons.py`。
> 每条都标了「怎么点 → 期望什么 → 实际什么」。跑一次 test_buttons.py
> 就等于把这个表逐条过一遍。

## 约定

- 状态列：`✅ 通过` / `❌ 失败` / `⚠️ 已知限制`
- 「点法」优先用 `data-act` / `id`（稳定的锚点），不用文案（会变）
- 每条断言都要**可证伪** —— 不做「页面还在就算过」这种橡皮图章

## 已知会「点不动」但**不是 bug** 的情况

- 阅读器里 `#rdPrevCh` 在第一章是 `disabled` —— 这是刻意的
- 榜单刷新时 `#ranksRefresh` 会 `spin` 并临时禁用 —— 防连点
- 搜索进行中再点搜索 = 取消上一次（`AbortController`），不是没反应

## 踩过的坑（修好后回归锁住）

1. **`『』` 反爬混淆**：`回『荡』` 当正文透出 → 用户看成乱码。
   修在 `base.deobfuscate()`，接入 `tidy_content()`。
2. **按钮文案当章节名**：目录首项锚文本是「开始阅读」。
   修在 `webfetch._is_nav_title()`。
3. **已缓存的旧正文不会自动变干净**：靠 `tools/retidy.py --apply` 重刷。
4. **搜索被最慢源拖住**：`as_completed` 等全部 → 改软截止。
   修在 `engine.search()`，见 `SEARCH_SOFT_DEADLINE`。
