## 零、结论先写

- **线上今天没有数据可判**（不是「没有新案例」）：`106.53.203.108` 第 **15 天**整机不可达
  —— TCP 22/80/443/8000 全部 `TimeoutError`（不是 `refused`）、ICMP 3/3 丢。
  拉不到线上日志，就不能说"用户今天没搜不到"。
- 本地实例补位 16 本真实书名：**14 本可读、1 本有结果但正文读不了、1 本候选=0**。
- 今天挖到的两个问题**都不在"0 条名单"里**，而都在**账本**上：
  ① `search.done` 的 `可读=` 数的是 `available`（目录能打开），前端绿标看的是
  `readable`（正文抽样通过）—— 同一份日志里两件事共用一个词，《我们仨》那一轮
  写着 `可读=1`，而唯一那本正文回「连接被拒绝」。
  ② 并行联网兜底**真的交回了候选**，`联网=` 却写 `not_needed`（"一次没跑"）——
  因为它前面那行的 `web_gave = 0` 默认值写在了 `join()` **之后**，把真值冲掉了。
- 顺带修掉一条**行为**：目录能开、正文全被判假时，旧逻辑认为"本轮成功"，
  联网门（门票是 `not any(r.available)`）一次都进不去 → 用户拿到一张读不了的卡。
  现在抽样出结论后**补一次联网**（有预算守卫）。

### 3.2 链路

1. **kunnu8 在 1.5s 时被收手切断**（`未回=1(kunnu8)`）。它只有一个能读的版本
   （84 章）；单独调它 **0.42s / 0.44s / 2.46s / 4.49s**（四个词），波动 10 倍，
   而它**没有声明 `budget_s`** → 收手 ①②③ 不为它让路。
2. registry 交来 `axxsw.net` 的 **20 章假目录**（目录静态可开、正文拒绝连接）。
   它标题**完全等于书名**（tightness=1.0）→ 收手门被喂饱（"至少一条确切命中"成立）。
3. 正文抽样明确判假（`sample_ok=False`），但：
   * `search.done 可读=` 数的是 `available` → 写 **`可读=1`**；
   * 抽样判假**没有一行日志**（`_sample_one` 只在整轮结束时报"提前收手/超预算"）；
   * 联网门 `not any(r.available)` → 有 available → **不出去找**。
4. 用户拿到一张点进去一个字都没有的卡，而日报读到的全是"成功"。

### 3.3 根因（三条，都改了）

| # | 根因 | 修法 |
|---|---|---|
| A | **同一个词两个含义**：`可读=` 数 available，产品绿标用 readable | 拆成 `可达=`（available）与 `可读=`（readable），新增 `正文=` 抽样账（判假**点名 host + 原因**） |
| B | **默认值写在真值之后**：`web_gave = 0` 排在 `web_thread.join()` 之后，把"并行兜底交回几条"冲成 0 → `联网=not_needed` | 默认值移到 join 之前，后面不许再写；`联网=` 现在能如实写 `preempt` |
| C | **「目录能开」被当成成功**：正文全判假也不触发联网 | 抽样出结论后补一道门：`late_evidence`（有结果 + 抽样有结论 + 全部判假 + 无一条 readable）→ 预算允许时**补一次联网**，并记 `web_late` / `联网=late` |

### 5.2 这条判据为什么没抓到它

- **A**：`可读=` 是**字面量直接写在 log_event 里**的一行统计，没有函数、没有名字，
  所以既没有单元测试盯着它，也没有人问过"它和前端用的 `readable_count` 是不是一回事"。
  → 现在抽成 `sample_ledger()`，并加了 AST 断言：`可读=` 里出现 `available` 就报红。
- **B**：默认值的位置**没有任何机制能检查**——它不报错、不改变任何计算结果，
  只让"真的出去搜过"变成"没搜过"。→ 现在加了**行号断言**：`web_gave = 0`
  必须出现在 `web_thread.join(` 之前；再加一条端到端（preempt 真交回候选 → `联网=preempt`）。
- **C**：**压根没有埋点**。抽样失败只有 `sample_note` 在内存里，落日志时被丢掉，
  于是"抽了、判假"和"没抽"在日志上完全一样。→ 新增 `正文=` 一格 + `search.sample`
  相关的 stats 字段（`sampled / sample_ok_n / sample_failed / sample_unverified`）。

```
$ .venv/Scripts/python.exe tools/mutate.py 账本
✓ 被抓住  [账本] `可读=` 数回目录可达（把「打不开正文」写成「能读」）
✓ 被抓住  [账本] 判假的 host 不点名（只剩一个数字，复盘查不到是哪个站）
✓ 被抓住  [账本] 判假超过 3 个时沉默截断（不写 +N）
✓ 被抓住  [账本] 并行兜底交回几条被默认值冲成 0（联网= 永远说「没跑」）
✓ 被抓住  [账本] 正文全判假时不再补联网（用户只拿到一张读不了的卡）
突变 5 条 · 问题 0 条
源码已逐字节还原 ✓
```

判据三问：

1. **会只因环境变吗**：不会。`可读/可达` 是 AST 静态断言；`web_gave` 是**行号**断言；
   `正文=` 是纯函数；补联网用假源（`FakeTocSrc` 固定返回判假），不碰真实站点，
   也**没有任何耗时阈值**。
2. **把功能拆掉还绿吗**：不绿。5 条突变各自对应一条断言，删除/回退功能当场报红。
3. **只验正向吗**：不是。补联网有三条反向断言（正文能读 / `sample=0` / `discover=0`），
   场景 9 另有"并行兜底交回候选才叫 preempt"的成对断言。
