### 根因（主线）：我们自己把目录拆碎了

`https://cn.shubaoc.com/novel/bpo/` 是**《我的阿勒泰》的真书页**，抓下来一看有
**41 条章节链接**，标题「我的阿勒泰(李娟)」。可我们的解析给了 0 章。三个坑叠在一起：

1. **章节 id 是 base32**（`1u0ri`、`1u11f`、`1u0tl`）。`_template()` 只把 `\d+` 换成 `#`，
   一条 `/novel/bpo/1u0ri.html` 变成 `/novel/bpo/#u#ri.html` —— 42 条链接分成 **42 个「模板」**，
   每组 1~3 条，全都够不到 `min_items=8` → 整本书 0 章 → 判成「没有目录」。
2. **slug 里的数字被当成章节号**（`1u11f` → `1`、`11`）。`_chapter_keys()` 会挑「变化最多的列」
   当章号再据此重排 —— 一本顺序正确的书会被排成乱序。
3. **散文集的目录不叫「第N章」**。`toc_quality()` 只认「URL 单调 + 标题带第N章」。
   《我的阿勒泰》的目录是「自序 / 第一辑 阿勒泰文字（2007-2009） 我所能带给你们的事物」，
   ratio=0 → 就算模板归对了，一份 40 条的真目录也只给 **0.35 分** → `analyze` 判 unknown。

> **这三天的三本书（乡土中国 / 素食者 / 我的阿勒泰）全是散文集或严肃文学，
> 恰好全落在第 3 条上。** 这就是"冷门书搜不到"背后的系统性原因 ——
> 不是站上没有，是我们的判据只认得网文。

### 根因（辅线）：核实 5 个候选，日志只记 2 条

10-30 的日志原样：

```
联网搜索 → Bing 3 条 / 百度 2 条 → 核实候选站点 5 个地址
候选核实失败 www.99csw.com: HTTP 403
候选核实失败 www.academia.edu: HTTP 403
没找到能用的
```

**另外 3 个候选一个字都没有**。原因是 `discovery._verify()` 里
`kind != "toc"` 那条分支**静默 return** —— 页打开了、只是不是目录。
复盘时只能看到"两个站挂了"，而真正的事实是"5 个里 3 个根本不是书页"。
这两种病因的处置完全相反：前者换搜索词，后者说明目录识别有 bug。

## 三、举一反三

### 同类站会不会中招？

- **2 条已经实测**：`cn.shubaoc.com`（base32 id）、散文集类目录（任何非网文）。
- **1 条新增风险被验证到**：当页面认不出目录区时，`/book/2345/…/book/2352/` 这种
  单调递增的「猜你喜欢」会以 0.35 分压过 0.0 分的 slug 真目录 —— 用户点开一本书，
  目录是别人的书。已加「挂不挂在这本书下」这一层排序并排在质量分之前。
- **预计还影响**：所有用 base36/base32 生成章节 id 的站 + 所有散文/文集/学术类书的
  目录。无法从现有 registry 反推具体个数（目录被拆碎的站本来就没被收录过，
  `toc_tpl` 里看不到痕迹），只能用真实书页抽样测。

### 这条判据为什么没抓到它？

| 现象 | 缺的是 |
|---|---|
| 42 章被拆成 42 个单条组 | `_template` 的归一化只认纯数字，**清单漏项** |
| 真目录被判 0.35 | `toc_quality` 只有两个正交判据，**压根没有「页面自己说是目录」这条证据** |
| 核实 5 个只记 2 条 | `_verify` 的 shape 分支**没埋点** |
| `discover` 只有 `候选=N` | 没有把核实结果按原因分桶，**只有结果没有过程** |

## 六、欠账（按优先级）

1. **`skipped_dead` 会整站封杀**：8 个不健康站里 **5 个是纯 shape 失败**
   （`readnovel` / `meipian` / `youku` / `lib.cidp.edu.cn` / `zgxcfx`，`fail_down=0`）。
   它们确实"给的那个地址不是书页"，但**判死的是整站** —— 同一站换个 URL 也再也不试。
   今天**没有改**：查完数据发现这 5 个地址确实都该否（视频搜索页 / PDF / 新闻页 /
   小说站的搜索页），改健康判据会让这些页面反复占用核实预算。
   正确做法是区分「站不行」和「这个 URL 不行」，属于设计层改动，需要单独一轮。
2. **99csw / academia 是 Cloudflare 挑战页**（`Just a moment...`），换 UA 无效，
   只能上 headless 或放弃。这是"我们开不了页"，不是"站上没有" ——
   所以《乡土中国》《素食者》**还不能**转成"确认全网无源"。
3. `leshu8.com` 有《乡土中国》的书页（标题、封面、简介都对），但**没有目录**
   （`kind=chapter`、toc=0），大概率是电子书下载站（要登录/客户端）。
4. `_order_chapters` 对散文集无能为力（标题里没有章号）—— 现在靠"锚点内顺序"兜住，
   但页面顶部「最新章节」块如果恰好落在锚点窗口内，仍会排到第一。
5. `wikisource` / `xbqg5200` 仍靠熔断每小时复活占名额（老账，四天没动）。
