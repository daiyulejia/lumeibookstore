## 二、主线：三个 host 占 30% 源池，被判中 58 次也不走

- `sites_searchable=10`，其中 `sk.3qdu.net/.com/.org` 是**同一个站（3Q中文网）**
  的三个 host，`search_kwblind` = 58/47/31，`search_hit` = 0/1/1。
- 实测：对「三体」「斗破苍穹」「zzqqxxbukCunZaiDeShu」都返回**同样 42 条**
  推荐链接（`/?s=` 被当空气）。判定是对的，问题是"判中了不动手"。
- 根因：**「偶然命中过一次」把两条出口同时关闭**。
  ① 作废条件要求 `search_hit == 0`；② `needs_keyword_control()` 同样要求
  `search_hit == 0`。不认词的站回整站推荐位，用户搜的那本碰巧在里面 → hit+1
  → 从此既不作废也不再被问。两条**独立**判据共用一个前提，一次偶然就能永久击穿。
  与 11-17「只进不出」同母题，方向相反（过线即免疫）。
