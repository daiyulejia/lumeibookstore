## 踩到的坑（下次直接用）
1. **同一工作区里有另一个会话在并发改文件**（registry/adapter/ranks 在 09:20–10:03 一直变），
   导致我两次 ship 假红（mutate 报"测试期间源码被外部改动"、Chrome 判据时红时绿、baseline 红）。
   教训：**ship 前先确认没有别的会话在写这个仓库**（看文件 mtime + python 进程）。
2. 这个 shell 里 `env -u http_proxy … python -c "多行"` 会**静默吃掉输出**（多行参数被 MSYS env 破坏）。
   要么 `unset … ; python -c`，要么把脚本写成文件再跑。
3. `curl` 在这台机器上对线上 HTTP 返回空（`-w` 也不打印），改用 `.venv/Scripts/python.exe` + urllib。
